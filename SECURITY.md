# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.0.x   | :white_check_mark: |
| < 7.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within REA-Neural:
1. Please do NOT open a public issue.
2. Email the maintainers directly at `security@bio-colab.org` or report via GitHub Security Advisories.
3. Include detailed steps to reproduce the issue and the affected Windows binaries.

All reports will be acknowledged within 48 hours, with a patched release prioritized for confirmed issues.
