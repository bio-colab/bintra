# Bintra v1.0.0: Autonomous Continuous Semantic Reverse Engineering & Binary Analysis Framework

We are proud to announce the **inaugural official release of Bintra (v1.0.0)**!

`Bintra` is an agent-native, next-generation reverse engineering and binary analysis framework engineered independently for **Windows compiled software executables and libraries** (`.exe`, `.dll`, PE32, PE32+). Grounded in continuous representation theory from recent MIT CSAIL research (*"Sparks of Weight-Space Programming"*, November 2026), `Bintra` overcomes the limitations of traditional symbolic reverse engineering tools when analyzing obfuscated native code and hybrid embedded AI binaries.

## 🚀 Key Release Highlights

### 1. 🎨 Visual Identity & Brand Architecture
- Official visual identity assets integrated into [`assets/`](assets/): 2:1 social banner, 16:9 3D cognitive architecture hero graphic, square application icon, and dark/transparent hexagonal vector logo marks.
- CLI banner in `bintra` with unified command routing and UTF-8 console output.
- Complete brand guidelines, color palette, and vector specifications documented in [`assets/README.md`](assets/README.md).

### 2. 🧬 Continuous Semantic Deobfuscation
- **Algebraic Opaque Predicate Elimination:** Identifies zeroing operations and dead conditional jumps via Capstone linear sweep with strict instruction-boundary parsing, completely eliminating false positives from constants and immediate operands.
- **Localized Cadence CFF Pruning:** Detects and simplifies Control Flow Flattening dispatcher loops using windowed cadence regularity analysis ($\le 1024$ bytes, regularity $\ge 0.35$), clustering exclusively on state variable storage locations while rejecting high-entropy cryptographic payloads.

### 3. 🌐 Symbiotic Ghidra Integration & High P-Code IR
- **64-Dimensional High P-Code SSA Vectorizer:** Lifts decompiled Ghidra P-Code operations into architecture-invariant continuous semantic vectors, matching routines across architectures using cosine similarity threshold `MATCH_THRESHOLD = 0.90`.
- **Authenticated Queued-Poll Live Bridge:** Provides localhost HTTP JSON-RPC 2.0 queueing (`ThreadingMixIn` on `127.0.0.1:41718`) polled at `1.0s` intervals by [`BintraLiveBridgeService.py`](ghidra_scripts/BintraLiveBridgeService.py) with `AUTH_REQUIRED` token validation, bounded `cap.tempdir.marker.write` discovery (`--no-temp-marker` opt-out), and explicit `rva`/`va` image-base normalization alongside offline mutation plans.

### 4. 🛡️ Goal-Driven Surgical Binary Patching
- **Stack Proprioception:** Verifies stack frame balance ($\Delta RSP / RBP = 0$) across instruction boundaries before committing any binary patch.
- **PE Checksum Synchronization:** Automatically recalculates Windows PE structural checksums for file integrity.
- **Fail-Closed Target Immutability:** Enforced by the `ExecutionGuard` reference monitor, preventing accidental target truncation or corruption.

### 5. 🔍 Windows System Intelligence & Forensics
- **Windows Error Reporting (WER) & Application Event Log:** Integrated with native Win32 `wevtapi.dll` with automated fallback to `wevtutil`.
- **Live Hardware & Driver Matching:** Queries Plug and Play (PnP) hardware IDs, resolves driver packages via `SetupAPI`/`CfgMgr32`, and correlates error problem codes (`CM_PROB_*`).
- **Kernel Drivers & Process Introspection:** Enumerates loaded kernel drivers with image bases via `PSAPI`, maps active services via `Advapi32`, and identifies file locks via `Restart Manager`.
- **Multi-Stream MiniDump (.dmp) Parser:** Decodes system information, module lists, thread contexts, and exception records to pinpoint Access Violation (`0xc0000005`) crash root causes.

### 6. 🤖 Agent-Native Model Context Protocol (MCP) Server
- **JSON-RPC 2.0 Compliant:** 34 specialized reverse engineering and diagnostic tools.
- Strict batch request support and `null`-id notification handling for seamless integration with AI coding assistants (Claude Desktop, Antigravity, Cursor, Gemini CLI).

### 7. 🧪 Rigorous Quality Assurance & Test Verification
- **195 Unit, Telemetry, and Regression Tests:** Executed across Python 3.11 and 3.12 on Windows Native CI, plus Ubuntu Python 3.12 cross-platform graceful-degradation CI (with explicit `win32` guards for NT-only introspection).
- **Boundary, Security, & Protocol Coverage:** Verified across malformed PE headers, invalid byte streams, read-only VAD/memory/ETW/MiniDump telemetry contracts, `AuditLogger` fail-closed/degraded CLI signaling, and strict MCP schema validation across all 34 registered tools.

## 📦 Installation & Quick Start

### Install via pip:
```powershell
pip install bintra_neural-1.0.0-py3-none-any.whl
# Or install in editable mode from source:
git clone https://github.com/bio-colab/bintra.git
cd bintra
pip install -e .
```

### Quick Verification:
```powershell
# Run the 10 Metaphorical Senses on a binary
bintra sense --file path\to\target.exe

# Inspect PE headers and mitigations
bintra inspect --file path\to\target.exe

# Start Agent MCP Server
bintra-mcp
```
