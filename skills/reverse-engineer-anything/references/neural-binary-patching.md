# Neural Binary Patching & Lipschitz Bounds

## 1. Principles of Gradient-Free Weight Surgery

Traditional machine learning updates all weights across all layers via backward propagation. In contrast, **Neural Binary Patching** treats weights as an executable binary file on disk (`.safetensors` or `.gguf`), modifying only targeted parameters at specific byte offsets.

---

## 2. Supported Patch Operations

### 2.1 Rank-1 Nullifying Update (`rank_1_nullify`)
Used when an isolated directional vector $v \in \mathbb{R}^{d}$ within an attention or MLP projection causes undesirable attractor states (e.g., infinite loops or safety refusals).
$$W_{new} = W_{old} - \alpha \cdot (W_{old} v) v^T$$
Where:
- $v$ is the unit eigenvector associated with the degenerative loop attractor ($v^T v = 1$).
- $\alpha \in [0.8, 1.0]$ is the damping factor.

### 2.2 Sparse Coordinate Masking (`sparse_clamp`)
Used to eliminate numeric outliers or toxic trigger tokens:
$$W_{new}(i, j) = \begin{cases} 
0 & \text{if } (i, j) \in \text{TargetMask} \\ 
W_{old}(i, j) & \text{otherwise} 
\end{cases}$$

### 2.3 Selective Column Direction Subtraction (`column_direction_subtract`) & Additive/Subspace Edits
Used to cure localized attractor loops by subtracting the dominant loop direction from only the top-$K$ columns most aligned with it, plus full-mode zeroing (`subspace_zero`) or targeted steering (`vector_add`):
$$W_{new}[:, S_K] = W_{old}[:, S_K] - \alpha \cdot u_0 (u_0^T W_{old}[:, S_K])$$
Where $S_K$ indexes the top-$K$ columns (`num_columns`, default 64) and `WeightPatcher.apply_patch` supports `rank_1_nullify`, `sparse_clamp`, `subspace_zero`, `vector_add`, and `column_direction_subtract`.

## 3. Mathematical Safety Guarantees (Bounding Collateral Damage)

To prevent catastrophic forgetting, every patch generated by `REA-Neural` must satisfy the **Frobenius Energy Bound**:
$$\Delta_{rel} = \frac{\|W_{new} - W_{old}\|_F}{\|W_{old}\|_F} < \epsilon_{threshold}$$
Where $\epsilon_{threshold}$ defaults to $0.005$ (0.5% relative matrix disruption).

### Lipschitz Perturbation Bound
For any input activation $x$ with $\|x\|_2 \le B$:
$$\|W_{new} x - W_{old} x\|_2 \le \|\Delta W\|_2 \cdot B \le \sigma_1(\Delta W) \cdot B$$
Because $\Delta W$ is strictly rank-1 or sparse, the maximum singular value $\sigma_1(\Delta W)$ is bounded and known *a priori*, guaranteeing that unrelated representations experience strictly bounded distortion.
